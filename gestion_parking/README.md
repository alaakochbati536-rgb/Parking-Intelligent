
# Parking Intelligent 🚗

## Présentation du projet
Application de pointage d'un parking intelligent avec reconnaissance des plaques d'immatriculation tunisiennes.

## Objectif
Automatiser la gestion des entrées et des sorties des véhicules.

## Fonctionnalités
- Détection des voitures.
- Reconnaissance des plaques tunisiennes.
- Enregistrement de la date et l'heure d'entrée.
- Enregistrement de la date et l'heure de sortie.
- Calcul de la durée de stationnement.

## Technologies utilisées
- Python
- HTML
- CSS
- JavaScript
- MySQL
- OpenCV
- EasyOCR
- Git et GitHub
